# Grace & Gather room comparison prototype
Buildless static prototype. Serve dist/ using HTTP. No app/backend changes.
First visit chooses Catholic, Protestant or Orthodox; stored only in this browser. Change via Profile > Preferences > Christian tradition.
All scenes are stylized design studies. The Orthodox icon screen uses original simplified geometric figures and hanging lamps; it is not a reproduction of sacred icon art. Architectural reference: https://www.oca.org/orthodoxy/the-orthodox-faith/worship/the-church-building/icons
Reuses existing church WebGL renderer, walnut texture and original synthesized ambience. No remote media or new licensed assets. Journal is unsaved and never transmitted. Account destinations are clearly marked preview placeholders.
