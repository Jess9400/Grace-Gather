# Open study-note sources

These notes are adapted from:

- Aquifer Open Study Notes © 2026 Mission Mutual, adapted from Tyndale Open Study Notes © 2023 Tyndale House Publishers: https://github.com/BibleAquifer/AquiferOpenStudyNotes, release v2026-10-20, CC BY-SA 4.0.
- Biblica Study Notes © 2023 Biblica Inc., adapted by Mission Mutual: https://github.com/BibleAquifer/BiblicaStudyNotes, release v2026-11-02, CC BY-SA 4.0.

License: https://creativecommons.org/licenses/by-sa/4.0/. Only notes with source metadata `review_level: Professional` are imported. The eligible material is in English and Russian; these releases do not record professional review for Portuguese, Spanish, or Biblica notes, so those notes are not displayed. These are general study notes, not a Catholic or Orthodox imprimatur or an exhaustive account of every tradition. The imported collections cover the 66 books common to the Protestant canon; they do not provide deuterocanonical notes.

Changes: the importer converts HTML to plain text, removes unrelated metadata, groups notes into language/book files and retains title, passage interval, text and source. It does not generate or paraphrase commentary. The original releases provide the full source and metadata. To reproduce run `mobile/scripts/import-open-study-notes.py` with the original English-json, Portuguese-json, Spanish-json and Russian-json ZIP assets from each release in AQUIFER_ZIPS and BIBLICA_ZIPS. Changes are released under CC BY-SA 4.0.
