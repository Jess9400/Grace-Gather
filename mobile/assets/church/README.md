# Church ambience

`ambience.m4a` is Johann Sebastian Bach's Goldberg Variations, BWV 988: Aria,
performed by Kimiko Ishizaka for the Open Goldberg Variations project.

- Recording: https://commons.wikimedia.org/wiki/File:Goldberg_Variations_01_Aria.ogg
- Recording dedication: https://creativecommons.org/publicdomain/zero/1.0/
- Original Ogg file SHA-1: `7955e74a97024b64c3ab2e4733e4d72db3654f4a`.
- This copy is the full recording re-encoded as AAC at 96 kbps, with a short
  fade at the start and end for the app's looping playback.
