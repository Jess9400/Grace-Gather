# Confessional walnut

`walnut-albedo.jpg` is a locally bundled 1024 × 1024 matte walnut albedo texture (JPEG quality 85). It was created with the built-in image generation tool, then resized and compressed for mobile. No runtime image service or remote texture is required.

Generation prompt:

> Use case: photorealistic-natural. Asset type: tileable albedo texture for a small 3D walnut door in a quiet, intimate mobile app. Create one square 1024x1024 seamless photographic material swatch of dark natural American black walnut, quarter-sawn, fine vertical grain with delicate irregular fibres, subtle pores and gentle natural variation. Neutral dark chocolate brown with slightly grey undertones, matte sanded wood, low contrast. Even diffuse flat lighting with NO baked shadows, highlights, glossy varnish, orange or golden cast. Straight-on orthographic macro material only, filling the entire image edge to edge. No door, no frame, no planks or seams, no objects, no text, no vignette. Grain should run vertically and tile seamlessly on both axes. Real timber, not a stylized game texture.

The mesh uses this texture for fine irregular grain. Geometry, soft lighting, hinge movement and aged-brass shading remain code-generated. The original generated PNG is retained outside the repository; the optimized JPEG is the production asset.
