# Church ambience

`ambience.m4a` is an original 64-second seamless loop generated in code for
Grace & Gather (no samples, recordings or third-party material). It is meant
to feel light: soft, high "aah" voices (a small synthesized ensemble shaped by
soprano vowel formants, with gentle vibrato) moving through bright major
chords in D, glass-like sparkles from the D major pentatonic, an airy breath
of filtered noise and a long, bright hall reverb applied circularly so the
loop has no seam. No low drone. AAC 96 kbps stereo.

To replace it, drop in another loopable file at the same path and keep a note
of its licence here. Only use audio that permits use inside a commercial app
(for example Freesound CC0, or a recording made for the app).
